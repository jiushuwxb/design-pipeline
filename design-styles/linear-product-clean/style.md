# Linear Product Clean

Use this style for developer tools, B2B SaaS, productivity apps, roadmaps, issue trackers, and operational product sites.

## Design Intent
- Feel engineered, calm, and exact.
- Emphasize product state, keyboard efficiency, command surfaces, and organized information.
- Prefer restrained details over dramatic marketing treatment.

## Layout Rules
- Use split sections with product panels and concise copy.
- Favor dashboards, command menus, timelines, tables, and status rows as real product proof.
- Maintain tight but readable density.

## Component Recipes
- Panels: subtle borders, muted surface contrast, precise spacing.
- Status chips: small, semantic colors, no loud badges.
- Lists/tables: clear columns, stable row heights, hover affordance.
- Navigation: compact, predictable, utility-oriented.

## Motion Rules
- Motion should communicate state transitions, command response, or panel reveal.
- Use minimal durations and avoid theatrical transitions.

## Negative Rules
- No playful illustration style.
- No large marketing blobs.
- No excessive card decoration.
- No low-contrast text below readable thresholds.

## References
- Inspired by clean developer-product interfaces and modern issue/productivity tools.
