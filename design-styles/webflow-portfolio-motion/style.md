# Webflow Portfolio Motion

Use this style for creative portfolios, case studies, agencies, personal brands, and visual studios.

## Design Intent
- Showcase work quickly with strong visual hierarchy.
- Use large typography, project grids, editorial composition, and scroll rhythm.
- Each section should feel curated rather than templated.

## Layout Rules
- Hero can be bold and typographic, but must include a clear identity or offer.
- Use project cards, case-study rows, marquee-like proof strips, and image-led sections.
- Alternate dense project grids with spacious narrative sections.

## Component Recipes
- Project card: image/preview, category, year, short outcome, hover transition.
- Case study block: problem, role, result, visual.
- CTA: direct and simple, no decorative overbuild.

## Motion Rules
- Use scroll reveals, image parallax, and hover image shifts sparingly.
- Motion should support portfolio browsing and case-study progression.

## Negative Rules
- No generic SaaS bento layout unless PRD asks for it.
- No stock-photo atmosphere without real project/product signal.
- No unreadable oversized text on mobile.

## References
- Inspired by Webflow showcase, creative portfolio, and agency site conventions.
