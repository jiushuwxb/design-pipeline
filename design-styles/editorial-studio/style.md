# Editorial Studio

Use this style for architecture, photography, design studios, luxury services, and premium brand presentations.

## Design Intent
- Feel curated, quiet, and confident.
- Use strong editorial type, deliberate image placement, and low-saturation palettes.
- Let content and imagery carry the design.

## Layout Rules
- Use magazine-like section structure: title, image, caption, detail text.
- Favor asymmetric grids, generous margins, and controlled whitespace.
- Keep the first viewport elegant but concrete about the brand/object/service.

## Component Recipes
- Image block: stable aspect ratio, caption, subtle border or none.
- Service list: clean typography, short descriptions, strong dividers.
- Case study: large visual, small metadata, clear outcome.

## Motion Rules
- Use slow fades and subtle image reveals.
- Avoid flashy UI motion.

## Negative Rules
- No loud gradients.
- No tech-dashboard visuals unless PRD asks.
- No excessive cards.
- No playful icon sets.

## References
- Inspired by editorial, studio, architecture, photography, and luxury portfolio websites.
