# Awwwards Motion Brand

Use this style for high-impact brand sites, launch pages, visual campaigns, and creative web experiences.

## Design Intent
- Create a memorable first impression with strong composition and confident type.
- Favor one powerful visual idea over many small decorations.
- Use asymmetry intentionally while keeping content legible.

## Layout Rules
- Hero must have a distinctive visual system, not only gradient background.
- Use full-bleed sections, editorial breaks, strong transitions, and cinematic pacing.
- Keep navigation discoverable even when composition is expressive.

## Component Recipes
- Hero: bold type, direct offer/brand signal, immersive visual area.
- Feature block: one statement, one visual, one proof point.
- Gallery/sequence: consistent aspect ratios and controlled spacing.

## Motion Rules
- Motion can be expressive: reveals, scene transitions, text masking, parallax.
- Avoid motion that blocks reading or navigation.

## Negative Rules
- No chaotic overlapping text.
- No inaccessible contrast.
- No purely atmospheric dark hero without product/brand signal.
- No generic AI-generated 3D object unless it supports the concept.
