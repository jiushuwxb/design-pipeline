# Framer SaaS Minimal

Use this style for clean startup sites, AI tools, developer products, and product-led landing pages.

## Design Intent
- The page should feel lightweight, precise, and fast.
- Use whitespace and clean typography instead of heavy decoration.
- Product proof matters more than abstract illustration.

## Layout Rules
- Hero should be direct: product/category, one strong value prop, CTA row.
- Use simple feature rows, comparison sections, pricing blocks, and testimonial strips.
- Maintain consistent max-width containers and predictable vertical rhythm.

## Component Recipes
- Cards: flat with fine borders, no heavy shadows.
- Inputs: clean, full-width on mobile, clear focus states.
- Product preview: real UI panels, not atmospheric placeholders.
- Pricing: compact columns with clear selected/recommended state.

## Motion Rules
- Fade/slide reveals should be short and quiet.
- Use hover transitions for affordance, not spectacle.

## Negative Rules
- No oversized decorative gradients.
- No noisy 3D elements.
- No excessive rounded pills.
- No vague icon-only feature claims.

## References
- Inspired by common Framer template and minimalist SaaS visual language.
