# Dark 3D Tech

Use this style for AI platforms, data infrastructure, cyber products, developer platforms, and futuristic product stories.

## Design Intent
- Create depth and precision without becoming noisy.
- Use dark layered surfaces, fine grids, luminous accents, and product/state visualization.
- Prefer technical credibility over sci-fi decoration.

## Layout Rules
- Hero should include actual platform/product signal: terminal, dashboard, model graph, pipeline, or data visualization.
- Use alternating dark surfaces and high-contrast product panels.
- Keep content dense enough for technical buyers.

## Component Recipes
- Metric panels: crisp numbers, trend indicators, small labels.
- Data visualizations: grid, line, node, flow, or architecture diagrams.
- Cards: fine border, muted fill, small highlight edge.

## Motion Rules
- Use subtle animated lines, data flow, rotating object, or glow states only when meaningful.
- Motion must stay smooth and non-distracting.

## Negative Rules
- No generic neon cyberpunk overload.
- No unreadable low contrast text.
- No random 3D sphere as the only product visual.
- No overuse of blue-purple gradients.

## References
- Inspired by mature AI/data platform and dark technical product websites.
