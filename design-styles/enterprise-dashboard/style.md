# Enterprise Dashboard

Use this style for admin systems, operations tools, CRM, monitoring, and internal business modules.

## Design Intent
- Prioritize scanability, density, and repeated use.
- Make information hierarchy obvious through layout, table structure, and state indication.
- Keep decoration low and controls predictable.

## Layout Rules
- Use sidebar/topbar, filter bars, KPI rows, tables, charts, and detail panels.
- Maintain stable dimensions for tables, cards, controls, and charts.
- Optimize for desktop first while keeping mobile readable.

## Component Recipes
- KPI card: label, value, delta, tiny trend, status.
- Table: sticky header, filters, row actions, empty/loading/error states.
- Detail panel: metadata, timeline/activity, primary actions.
- Chart card: title, range selector, legend, empty state.

## Motion Rules
- Use only functional motion: drawer open, row expand, loading skeleton.
- Avoid marketing hero motion.

## Negative Rules
- No oversized landing-page hero.
- No decorative cards around every section.
- No dense one-color blue/slate palette.
- No card-inside-card nesting.

## References
- Inspired by mature enterprise SaaS, admin dashboards, and operational tools.
