# Nike 鞋类官方商城 - 产品需求文档

## 项目背景
为 Nike 打造鞋类产品官方展示与销售官网。Nike 作为全球顶级运动品牌，官网需要承载新品发布、产品展示、品牌叙事与用户购买引导等核心功能，向消费者传递品牌精神，同时提供流畅的产品浏览与筛选体验。

## 目标用户
- 运动爱好者与球鞋消费者（核心用户）
- 潮流玩家与球鞋收藏者
- 运动装备研究对比者
- 品牌粉丝与复购用户

## 功能需求

### 1. 全局导航栏
- 固定顶部，滚动时保持可见
- Logo 居中或左侧
- 一级菜单：男子、女子、儿童、定制、发售日历
- 二级菜单（悬停展开）：按品类（跑步、篮球、足球、训练、休闲）、按系列（Air Max、Air Force、Dunk、Jordan、Pegasus）
- 搜索入口（支持关键词搜索鞋款）
- 购物车与用户账户入口
- 移动端汉堡菜单折叠

### 2. Hero 首屏
- 全屏主推鞋款大图展示，支持视频/静态轮播
- 至少展示 3 个推广位（自动轮播 + 手动切换）
- 每帧包含：鞋款名称、核心卖点文案、CTA 按钮（"立即购买"/"了解更多"）
- 支持点击跳转至对应产品详情页

### 3. 新品首发区块
- 横向可滚动卡片列表（桌面端支持拖拽、移动端支持滑动）
- 每张卡片包含：鞋款缩略图、名称、分类标签、价格
- 显示"新品"角标
- 点击跳转至产品详情页
- 支持"添加至收藏"快捷操作

### 4. 人气热销排行
- 网格布局展示 8-12 款热销鞋款
- 排序逻辑：按近期销量/热度降序
- 每款展示：排名序号、鞋款图、名称、分类、价格、评分星级
- 支持按性别/品类快速筛选切换

### 5. 按品类浏览
- 6 个品类入口卡片（跑步、篮球、足球、训练、休闲、滑板）
- 每个卡片为全幅背景图 + 品类名称叠加
- 点击进入对应品类列表页
- 展示该品类下精选鞋款数量提示

### 6. 经典系列展示
- 重点展示 Nike 核心鞋款系列：Air Max、Air Force 1、Dunk、Jordan、Pegasus、Vaporfly
- 每个系列一块独立展示区：系列名称、简短介绍、3-4 款代表鞋款
- 点击进入系列专题页

### 7. 发售日历
- 时间轴展示即将发售的鞋款
- 每款包含：发售日期、鞋款图、名称、发售价格、发售渠道
- 支持"开售提醒"订阅功能
- 已发售鞋款可标记"立即购买"状态

### 8. 品牌叙事区块
- 展示 Nike 品牌故事与核心价值
- 可持续环保材料说明（如 Nike Grind、Flyknit 环保科技）
- 运动员合作故事
- 搭配高质量品牌影像素材

### 9. 会员权益与 Newsletter
- 展示 Nike Membership 核心权益：免运费、生日礼遇、专属折扣、优先购买权
- 邮件订阅表单：邮箱输入 + 提交按钮
- 可选手机号注册入口

### 10. 页脚 Footer
- 多列布局：
  - 产品分类链接：跑步、篮球、足球、训练、休闲
  - 帮助中心：订单查询、配送说明、退换货政策、尺码指南
  - 关于 Nike：品牌故事、新闻资讯、投资者关系、可持续发展
  - 联系方式：客服热线、在线客服、门店查询
- 社交媒体链接：Instagram、微博、微信、抖音
- 版权信息与隐私政策链接

## 页面结构
```
├── 导航栏（固定顶部，Logo + 菜单 + 搜索 + 购物车）
├── Hero 首屏（全屏轮播，3+ 帧推广位）
├── 新品首发（横向滚动卡片列表）
├── 人气热销排行（网格，支持性别/品类筛选）
├── 按品类浏览（6 个品类入口卡片）
├── 经典系列展示（Air Max、AF1、Dunk、Jordan 等）
├── 发售日历（时间轴，即将发售鞋款）
├── 品牌叙事（品牌故事 + 环保材料 + 运动员合作）
├── 会员权益与 Newsletter（权益展示 + 订阅表单）
└── 页脚（多列链接 + 社交媒体 + 版权信息）
```

## 数据结构

### 鞋款产品
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 产品唯一标识 |
| name | string | 鞋款名称 |
| category | string | 品类（跑步/篮球/足球/训练/休闲/滑板） |
| series | string | 系列（Air Max/AF1/Dunk/Jordan/Pegasus/Vaporfly 等） |
| gender | string | 性别（男子/女子/儿童/中性） |
| price | number | 价格（CNY） |
| originalPrice | number | 原价（如有折扣） |
| rating | number | 评分（1-5） |
| reviewCount | number | 评论数 |
| isNew | boolean | 是否新品 |
| isHot | boolean | 是否热销 |
| tags | string[] | 标签（如"环保材料""联名""限定"） |
| releaseDate | string | 发售日期（ISO 日期格式） |
| colors | string[] | 可选颜色 |
| sizes | string[] | 可选尺码 |
| description | string | 鞋款描述 |
| features | string[] | 核心卖点列表 |
| thumbnailUrl | string | 缩略图 URL |
| images | string[] | 详情图 URL 列表 |

## 交互需求
- 导航栏二级菜单悬停展开，移动端改为点击展开
- Hero 轮播自动播放（5 秒切换），支持手动切换和触摸滑动
- 新品首发支持横向拖拽滚动（桌面端）和触摸滑动（移动端）
- 品类筛选切换时产品网格平滑过渡
- 发售日历支持"开售提醒"按钮交互（弹窗确认）
- 搜索输入实时联想建议（基于鞋款名称和关键词）
- 移动端响应式导航折叠为汉堡菜单

## 技术要求
- 纯静态 HTML/CSS/JS，单文件交付，或按模块拆分为多个文件
- 响应式布局，覆盖桌面端（1440px+）、平板（1024px）、手机（390px）
- 图片素材使用 Unsplash 免费可商用摄影作品（搜索关键词：nike shoes, sneakers, running shoes, basketball shoes 等）
- 动画优先使用 CSS transition/animation 实现，JS 仅用于复杂交互
- 兼容现代浏览器（Chrome / Firefox / Safari / Edge）
- 移动端禁用自定义光标，优化触控体验
- 使用 IntersectionObserver 实现滚动进入视口动画

## 数据模拟
- 产品数据使用 JSON 对象内联于 JS，模拟 20+ 款鞋款数据
- 涵盖跑步、篮球、休闲三大核心品类
- 包含 Air Max、Air Force 1、Dunk、Pegasus 等经典系列
