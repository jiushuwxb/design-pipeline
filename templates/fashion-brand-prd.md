# NOIR ATELIER 极简时装品牌官网 - 产品需求文档

## 项目背景
为 NOIR ATELIER 打造品牌官方展示网站。品牌定位为极简主义高级时装，以黑白美学诠释当代女性力量，需要向用户传达品牌调性、展示新品系列、并建立品牌认知。

## 目标用户
- 追求品质的时尚消费者（核心用户）
- 时尚媒体与买手
- 潜在合作伙伴与投资人

## 功能需求

### 1. Hero 首屏
- 全屏沉浸式品牌大图，极具视觉冲击感
- 模特时装大片 + 渐入动画（灰度 → 彩色）
- 左侧品牌文案区域：系列标注 + 超大标题（中文 + 意大利斜体混排）
- 核心品牌标语
- CTA 按钮引导至新品系列
- 底部滚动指示器

### 2. 新品系列展示
- 3 列网格布局展示 6 款核心单品
- 每张卡片悬停显示商品名称与价格
- 商品标签：新品 / 限量 / 热卖
- 图片悬停放大 + 去灰度效果

### 3. 型录 Lookbook
- 不规则网格拼贴布局（大图跨行 + 小图拼贴）
- 模拟杂志编辑排版风格
- 所有图片悬停交互效果

### 4. 品牌哲学
- 黑白反转区块（白底黑字，与其他深色区块形成对比）
- 左侧品牌理念文字
- 中间核心数据指标（全球精品店数量、每件耗时、面料产地）
- 右侧工坊 / 幕后照片

### 5. Newsletter 订阅
- 居中极简邮件订阅表单
- 输入框 + 提交按钮

### 6. 页脚 Footer
- 4 列布局：品牌简介、探索链接、服务链接、联系方式
- 社交媒体链接：Instagram、小红书、微信
- 版权信息

## 设计风格参考
- **美学方向**：编辑级极简奢品，暗黑高级感
- **品牌名**：NOIR ATELIER（法式命名）
- **主色调**：纯黑 #0a0a0a 背景 + 纯白 #fafafa 文字，极致黑白对比
- **点缀色**：香槟金 #d4af37（可选点缀，非强制）
- **字体方案**：
  - 标题：Cormorant Garamond（高级衬线体，300 字重，中文混排 italic）
  - 正文：Jost（现代几何无衬线，300 字重）
- **构图**：大面积留白、不对称分割、分栏对比
- **氛围关键词**：静谧、力量、克制、奢华、当代

### 视觉参考品牌
- The Row、Jil Sander、Lemaire 等极简时装品牌的官网风格
- 编辑级摄影 + 克制的排版系统

## 页面结构
```
├── 导航栏（固定顶部，LOGO + 菜单项 + 移动端汉堡按钮）
├── Hero Section（左文右图分栏，全屏高度）
├── 新品系列（Collection Grid，3×2 商品卡片）
├── 型录 Lookbook（不规则网格拼贴）
├── 品牌哲学（白底黑字反转区块 + 数据指标）
├── Newsletter（居中订阅表单）
└── Footer（4列信息 + 社交媒体）
```

## 交互需求
- 页面加载动画（黑色预加载线条）
- 自定义光标（mix-blend-mode: difference 反差效果）
- 导航栏智能显隐（向下滚动隐藏，向上滚动呼出）
- Scroll Reveal 逐块淡入动画（IntersectionObserver）
- Hero 图片滚动视差效果
- 移动端响应式导航（折叠菜单）

## 技术要求
- 纯静态 HTML/CSS/JS，单文件交付
- 响应式布局，覆盖桌面端（1440px+）、平板（1024px）、手机（640px）
- 使用 Google Fonts 加载字体（Cormorant Garamond + Jost）
- 图片素材使用 Unsplash 免费可商用摄影作品
- 所有动画优先使用 CSS 实现，JS 仅用于滚动交互
- 兼容现代浏览器（Chrome / Firefox / Safari / Edge）
- 移动端禁用自定义光标，保留原生指针
